# UrbanThread - Frontend

React frontend for the UrbanThread Cloth Shop e-commerce application.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server (Vite) |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |

## Tech

- React 17, Redux, React Router v6
- Material UI, TailwindCSS
- Vite (build tool)

See the root `README.md` for full project setup instructions.
